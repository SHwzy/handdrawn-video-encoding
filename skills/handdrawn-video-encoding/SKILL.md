# 同人手书的制作分析与分层编码

目标是保留叙事、神态、节奏与角色身份，用可替换素材和可重放的编辑关系完成作品。把原片理解为作者使用绘画、剪辑、合成工具搭建的工程：少量原画、重复素材、关键帧、遮罩和常见特效往往能解释复杂观感。先找能解释画面证据的简单制作方式，再选择代码或生成工具实现。简单方法是优先检验的假设，不是对原作者工程的断言。

本技能面向不同作品；角色名、时间段、批准版本和具体参数属于项目状态，不写成通用常量。用户最新指示优先。仅要求分析、复盘或更新技能时，只做相应工作。

## 原片用途与素材默认策略

尽量避免在原片上加工、换头、局部改色后作为成片主体。原片用于镜头观察、跨帧测量、构图和动作参考；人物、服装、背景应独立新绘或使用已有合格素材，再由代码组合。给生成工具提供原片参考不等于要求它编辑原帧；提示词要明确新绘目标、角色身份和姿态锚点。仅无人物且直接沿用的镜头允许使用原片画面。后来明确授权的特殊编辑按其范围执行，不把一次例外变成默认；已认可历史版本及依赖不因此返工或删除。

## 先分析制作关系，再生产素材

首次拆解、遇到不明运动或重复返工时，读 [观察与制作假设](references/shot-analysis.md)。需要生成背景、透明角色及绑定装置时，读 [素材与合成](references/assets-and-compositing.md)。处理代码显隐、描边、错色层和运镜测量时，读 [代码遮罩与运镜测量](references/code-masks-and-camera.md)。场景遮罩使用代码，不使用 H3 生成。处理已有工程时先读其当前状态；[历史复盘](references/lessons.md)用于理解规则来源，不作为所有新项目必读的制作参数。

1. **确定任务边界。** 核对片源、帧率、时间基准、目标角色、替换范围、保留内容和本轮交付区间。仅无人物且可直接沿用的镜头，才声明直接复用原片；不露脸但有头发、衣服、手或身体的镜头仍属于人物镜头。
2. **先看原片的连续关系。** 记录切镜、叙事动作和重音，再检查起点、终点、运动极值与快速过渡。除单镜头清单外，建立跨景别的共用素材关系：近景和眼部特写可能只是同一立绘的不同取景。
3. **提出可验证的制作假设。** 先尝试已有图层的位移、等比缩放、取景、遮罩、前后景视差和缓动；需要时再加入空间投影、姿态替换或生成视频。用至少起点、中间、终点验证。不能解释可见证据就换模型，不靠不断加参数掩盖。
4. **主动查成熟做法。** 不确定如何实现某种观感，或同一结构问题反复调不对时，先把现象转成常见制作问题，查 AE 等合成工具的官方说明或可信制作实例。核实它需要哪些图层、锚点和空间关系；不要等用户提供软件名或方法。理解其操作原理后可用代码实现，无需为了使用方法而强行改用该软件。
5. **按最难覆盖的取景规划素材。** 先检查现有素材能否覆盖全程和最大特写，再决定是否新画、扩图或补姿态。先验证一个有代表性的动态区间，再推广；用户指定复杂片段时，不擅自换成简单片段验收。

“画面斜着”不等于发生了旋转，“看起来变形”不等于需要网格变形，“新景别”不等于需要新原画。旋转、镜头畸变、人物动作等判断，需要跨帧对应点或轮廓关系支持。未观察到的运动自由度先保持固定。

## 按运动来源选择实现

| 画面证据 | 首先检验的制作方式 |
| --- | --- |
| 无人物、无需改动的镜头 | 明确列出时间段并直接复用原片 |
| 轮廓与姿态稳定，构图变化 | 同一素材的平移、等比缩放、裁切与缓动 |
| 人、前景、背景相对移动 | 分层平移、遮罩、不同速度；有空间证据时用平面投影 |
| 短周期迈腿、摆动 | 少量姿态循环与平移配合；用步频、步幅、地面速度验证 |
| 真实姿态、表情或遮挡变化 | 需要的姿态关键帧、局部绑定或新绘内容 |
| 短时复杂动作难以用已有素材表达 | 依据用户授权使用视频生成，提供关键帧、动作视频参考和详细描述，再裁取所需时长 |
| 模糊、抖动、点阵、马赛克、闪白、文字、粒子 | 明确作用层和时间的独立效果轨道 |

允许对难以补画的动作使用稀疏关键帧，不代表把可用取景、分层和特效实现的运动也降级为静帧播放。视频生成可接管一个完整短镜头；是否需要严格贴合首帧构图，由叙事、衔接和用户要求决定。不要默认增加不必要的逐像素配准工作。

## 视频生成的默认选择

需要生成复杂动作时，优先使用可用的 `h3-video-production` 技能：原生高分辨率、与当前模式匹配的加速 LoRA、对应低步数。Ref2VA 的 Turbo 4-step 使用 4 步；其他模式核对其配套方案。仍提供关键帧、角色身份参考、原片动作视频及详细描述，明确各输入用途。清晰度提升不等于动作改善，不默认通过关闭加速、堆高步数解决运动问题。

生成前逐张核对关键帧中的眼睛、嘴角、姿势与动作时间线是否一致；文字要求微笑或睁眼，不能抵消图像中的中性表情或闭眼终点。把关键动作写成可观察状态链，必要时将低点、闭眼、起跳、睁眼接入真实时刻的 Guide 条件，而非仅作为普通参考图。单段修正仍失败时，在授权范围内拆段，以实际生成的边界帧接力；先检查动作和接缝，再整合。

先针对输入、提示词和条件连接排查；若用户确认 H3 的模型能力不足，再按用户授权切换 Seedance，不自动产生付费生成。已认可并整合的 Seedance 素材继续保留，改变未来默认不意味着重做已有镜头。符合无人物条件的原片直接复用，以及代码可实现的独立素材分层运动，仍优先于视频生成。实际试验结论写进项目记录，不把单个镜头的评价推广成所有任务的能力结论。

## 首次分析与不确定性

尽量在首次分析记录完整的效果清单，但不声称有限的多模态观察能一次识别全部细节。采用两轮检查：先判断素材、动作、镜头和遮挡结构，再专门检查焦点、抖动、纹理、转场、字幕及粒子。快速移动、切点和效果起落处加密取帧；稀疏联系图不能证明运动节奏正确。

每项结论区分：**直接观察、待验证假设、测量结果、尚不确定**。光流、特征匹配和频域数据只是辅助证据；重复地砖、网点、模糊和人物动作可能污染估计。不要把噪声轨迹直接变成画面扭曲。

优先消除会改变资产和结构的高成本误判：是否同一立绘、是否真正旋转、哪些层一起动、哪些地方会露出、镜头接触点在哪里。少量可独立添加的特效允许后续补齐；预留其图层和效果接口，记录待复核项。若效果影响遮挡、覆盖或转场连续性，则应提早处理。既不以“可以后补”为由略过首次分析，也不因细节不确定就反复重做已成立的结构。

## 编码与合成的约束

- 先固定起止构图和关键时刻的视觉目标，再拟合轨迹：主体占画面比例、留白、目光/表情、接触点、前后景位置、速度起落。不能用一个全局倍率解决所有镜头的问题。
- 角色、背景、字幕、粒子和镜头使用明确的父子关系。需要同步的层共享驱动；需要视差的层保留相对关系。将人物放在地面上意味着接触关系一致，不意味着整块地板与人物共用二维缩放。
- 人物参考分清身份与表演用途：身份图中的泪花、笑容不自动带入新镜头。头部朝向和眼球视线分别核对，抬头向下看不等于低头；汗滴和眼下泪花也不是同一表情。俯视透视要核对头顶、后脑及肩部可见面，不能用压扁头型代替。
- 宽裙摆等会使按包围框宽度适配的人物意外缩小；背景人物应同时核对身高和鞋底接地点，不能用顶端对齐代替落地定位。遮罩内外若有不同眼神／表情，将局部表情状态绑定到相应显隐层，而非全局定时切换。
- 连续特写先检查是否能复用前一镜的完整立绘。用局部取景定位嘴部、眼部等锚点，保留原姿态和角度。没有证据不要额外旋转、扭曲或重新生成脸。
- 运动轨道同时记录方向、幅度、时长与速度曲线。快速移动后缓慢停止是需要还原的可见节奏；按运动选择缓出/缓入等，不机械套用匀速或对称平滑。
- 特效记录作用对象、叠加顺序、坐标空间和强度包络。抖动按镜头拆开；将整体推进与短周期残差分开，避免镜头末尾仍在乱跳。模糊背景后叠锐利点阵与整体模糊是不同结果。
- 资产记录路径、尺寸、透明方式、参考帧、锚点、覆盖范围和组归属；轨迹记录源帧/片段时间的换算、切点、层级和参数。不同镜头不跨切点插值，共用素材可以跨切点继续使用。
- 透明素材先预乘 alpha 再滤波/变换。与人物绑定的道具按角色组处理，观众与环境按遮挡关系独立。若用户另行明确授权换头等特殊编辑，应在资产阶段检查约束，不能把整幅重绘称为严格保留原身体。
- 完整背景优先独立生成并验收。发现结构破损时修复资产，不靠贴补丁、拉伸人物、重复边缘或原片隐蔽补洞遮盖。已有可靠的透明图层和素材可直接复用，无需重新生成。
- 替换前景的长度、轮廓或位置后，重新检查被其遮住的背景，特别是旧手掌、袖口、头发等残留；正常／鲜艳等多状态背景一起修正。瞳孔等局部切换先配准，再仅合成目标部位，避免整图生成差异变成脸部抖动。

## 自主迭代与验收

验证顺序是：**制作模型能否解释原片 → 素材覆盖与身份 → 起止构图 → 连续运动和节奏 → 特效细节 → 导出与时间线整合**。流程可以按任务缩短，但不能用后面的技术通过代替前面的视觉判断。

同一问题反复出现时，先复查假设、对应点、锚点和素材关系，再调数值。用户指出问题后，把反馈转成可检查的约束，主动查相邻镜头是否也受影响；不要只机械修改用户提到的单个参数，也不要无依据改动已经认可的部分。

提供正常速度原片/结果对照，必要时附慢放和起止静帧。有播放检查能力就检查完整授权区间；若实际只查看了静帧或分析了帧间指标，如实记录，不能称为已看完动态效果。回看还应有一次以原片为基准的检查，寻找“尚未实现的东西”，避免只盯着刚写的效果。

分开报告：

- 技术有效：时长、帧率、音轨、覆盖、透明边缘、无越界。
- 视觉检查：身份、姿态、构图、速度、遮挡、特效与切镜。
- 用户验收：哪一版、哪一段已认可；哪些仍需审看。
- 工程整合：认可版本是否进入主时间线，入口是否实际读取它。

100% 覆盖不能证明视觉正确。预览通过不等于全片完成；大图被放大后可见的细节不足，也不能被称作已达到最终交付清晰度。

## 交接与可重放

在项目状态中明确最新认可输出、完整生成命令、实际模块与参数依赖、已完成/待整合/待验证范围和下一步。更新过时入口说明，避免新对话误跑旧版本。记录真实提示词、输入、采用素材、生成任务和版本；只有摘要时明确标注。案例的倍率、抖动强度与时间点只属于该项目，不能复制成通用默认值。
