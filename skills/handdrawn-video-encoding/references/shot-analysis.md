# 从画面证据反推制作方式

用于首次分析、陌生效果、镜头反复调不对或跨镜头素材关系不清时。目标是让代理主动完成观察、假设、验证和方法检索，不把用户变成逐项指出遗漏的审片员。

## 1. 先形成“人会怎样做”的假设

原片的最终像素是多个操作叠加后的结果。直接为每一帧寻找任意变换，容易得到数学上能拟合、制作上不合理的运动。先尝试少量可解释操作：一张立绘、重复姿态、横向长背景、图层父子绑定、遮罩、摄像机关键帧和效果轨道。

这是可证伪的制作假设。不能因为人通常会复用素材，就忽略真实的转头、表情变化或遮挡。比较以下证据：

| 要判断的关系 | 低成本验证 | 判断错误的后果 |
| --- | --- | --- |
| 是否同一原画 | 用发饰、衣褶、嘴眼比例等跨镜头对应点，先尝试平移与等比缩放对齐 | 多生成素材，出现身份与表情跳变 |
| 是否真正旋转 | 比较同一对稳定点的连线角度随时间是否变化；先排除不同裁切和人物原有斜线 | 给稳定立绘添加错误角度 |
| 是否人物动作 | 对齐镜头运动后检查关节、轮廓和表情是否仍变化 | 用相机替代动作，或把相机变化当作补画需求 |
| 是否空间推进 | 比较近远景相对变化、地面消失线、柱子直线和人物接触点 | 整图拉扯、漂浮、布丁式晃动 |
| 是否短暂抖动 | 在分镜内扣除缓慢运动，检查残差是否跨多个稳定对象一致 | 将推进、变焦、跟踪噪声当作抖动 |
| 是否只是新取景 | 检查现有整张素材，而非仅看已裁切的上一张预览 | 无必要的扩图和新特写生成 |

有多个解释时，优先用已有素材和低成本变换做起点、中间、终点样例，比较它们能否解释同一组证据。选择的依据是覆盖证据、稳定性和制作成本，不是模型复杂度。

## 2. 首次分析怎样尽可能完整

### 连续观看与分层取样

1. 先了解授权区间的正常速度节奏、声音重音和叙事，再定位切点与动作段。无法实际播放时，可提取连续帧辅助判断，但记录这个限制。
2. 每段先取首尾、中间和运动极值，建立概览。不要固定每秒一张就停止。
3. 对快速位移、抖动、像素化、闪白、切镜和焦点切换等可疑区间加密取样：可先每 2–3 帧，极短效果再逐帧；具体间隔由源帧率和效果时长决定。
4. 跨切点比较资产关系。两镜头可以是硬切，但仍使用同一原画；共享原画也不意味着必须抹去原有硬切。
5. 第二轮只查特效：色彩/亮度、模糊与焦点、位移/旋转抖动、点阵/颗粒、遮罩/溶解/马赛克、文字、粒子。沿时间找进入、峰值和退出，而不是只记“有此效果”。

不要把上述清单当作每段都要添加的效果。观察不到就不添加；不确定就标记待复核。

### 用简单数据辅助，而不是替代观察

- 叠加首尾轮廓、检查对应点距离和角度，可区分平移、缩放、旋转和真实形变。
- 人物包围框、头顶留白和背景可见面积可以约束构图，减少反复凭感觉调倍率。
- 帧差有助于找切点、闪白和短暂纹理；它也会响应压缩、噪声与人物运动。
- 地砖、梁柱等稳定直线可用于校准空间；生成素材与原片不同，应分别测量各自的结构。
- 特征匹配/光流在重复网点、地砖、失焦和遮挡下可能失效。检查内点、时间连续性和多个位置的共识。高阶矩阵能拟合不代表物体真的这样运动。
- 高频纹理可能绑定物体，也可能是合成后叠在屏幕上的效果。比较物体运动时纹理是否跟着走，再决定坐标空间。

### 最小分析记录

可放在现有镜头清单中，不必另造复杂格式：

| 字段 | 内容 |
| --- | --- |
| 时间 | 源帧区间、帧率、预览零点、切点 |
| 资产关系 | 原片复用、共享立绘/背景、真正新增的姿态、绑定道具 |
| 运动 | 镜头与对象分别怎么动；方向、幅度、快慢和停点 |
| 构图约束 | 起止主体占比、留白、关键点和接触点 |
| 效果 | 作用层、顺序、坐标空间、进入/峰值/退出 |
| 证据 | 参考帧、对应点、连续观察或测量结果 |
| 置信与成本 | 已确认/假设/未确定；误判是否会重做素材或结构 |
| 实现与验证 | 最简单可行操作；用什么现象判定成立或否定 |

缺少细节识别并不意味着所有制作都要暂停。先解决高成本结构疑问；把可独立补充的细节留在效果轨道和待复核清单中。由代理主动回查这些项目，不能默认等用户发现。

## 3. 怎样参考成熟软件方法

不要把用户的视觉描述直接翻译成同名数学效果。例如“鱼眼感觉”可能来自前后景扩张差，“平滑”可能是在描述缓出，“抖动”可能包含一次快速平移。先明确画面事实，再查对应制作操作。

当原因不明或同类修改持续无效时：

1. 将现象表述成工具无关的问题，例如“同一立绘从嘴部快速移到眼部并减速停住”。
2. 检验常见制作操作能否直接解释：预合成的缩放/位置关键帧、缓动曲线、父子层、遮罩、分层视差、摄像机投影等。
3. 查官方文档确认操作行为与输入条件，必要时查有实际工程/步骤的制作实例。教程中的具体参数不能原样套到当前素材。
4. 把其原理转为本工程的层级与轨迹。代码和 AE 都是实现载体；没有用 AE 也可以使用同一制作模型。
5. 保存选择依据和实测结果。若证据支持特殊手绘变形，再升级制作方式。

可按问题查阅的官方入口（内容可能更新，实际使用时重新核对）：

- [AE 摄像机与兴趣点](https://helpx.adobe.com/lu_en/after-effects/desktop/work-with-layers/camera-layer/cameras-lights-points-interest.html)
- [AE 三维图像与消失点数据导入](https://helpx.adobe.com/nz/after-effects/desktop/import-files/import-and-add-3d-models/preparing-importing-3d-image-files.html)

这些入口说明的是成熟工具能力，不证明某个 PV 的原工程采用了它们。

## 4. 小型实例：方法如何迁移

### 从嘴部移向眼部

先查看前一镜的完整人物素材是否已有嘴和眼。若轮廓与表情相同，用同一立绘定义两个取景锚点、起止大小和背景留白。角色角度无变化证据时保持不变。移动速度按原片选择先快后慢等曲线；镜头硬切与切入后的连续移动分别处理。不能因为手边只有一张裁过的眼部预览，就认定需要扩图。

### 走廊或教堂推进

正对镜头的单一平面，在固定焦距的直线推进下是等比放大；真实空间中不同深度有不同变化率。需要空间感时可用地砖汇聚线和墙角构造简化地面、侧墙、远墙平面，再移动相机。人物接地点由同一空间投影约束。先确定起止构图，避免“物理模型成立但推进太小”。正常透视不自动弯曲直柱；不要为了显得更立体随意叠鱼眼或高阶变形。

### 跑步循环

检查迈腿周期、步幅、人物起伏、地面滚动和前后景速度是否协调。只有两张姿态也可能表达跑动，但大步幅配慢地面会显得滑步。若复杂动作在允许时间内难以用当前资产表达，可使用已授权的视频生成：关键帧约束身份、参考视频约束动作，详细描述方向、步频、场景与禁止的变化。接受的完整短片可直接作为镜头，再叠字幕和必要效果。

## 5. 验证新规则是否真的改变决策

黑闪之间即使只有数帧，也要单独取样确认人物和道具状态，不能由相邻相似画面推断为同一立绘重复。人物检查须分别记录身体朝向、脸部侧向、注视对象和睁闭眼；同一姿态在现实／遮罩世界中可能有不同表情。风格化雨迹等效果还应区分连续粒子运动与逐帧随机替换，尖尾与厚端的朝向也会改变速度方向感；以原片和用户认可的观感决定，不强求物理连续。

更新本技能后，用几个不同情形检查推理是否仍成立：

- 多个景别的姿态完全一样：应首先尝试复用，不能每镜一张新图。
- 真实转头露出新脸侧面：不能因为偏好复用而强行只做二维缩放。
- 遗漏了可后加的点阵：补效果并检查顺序，无需重生背景。
- 镜头运动会露出未知区域：先解决覆盖，不能拖到最终渲染补洞。
- 画面完全没有人物：先判断直接复用是否满足任务；只有“没有目标角色”并不足以允许沿用原片人物画面。

这些是判断用的反例，不是要求每轮都重新生成一套测试作品。

需要实际估计旋转、缩放、平移及分离抖动时，按 [代码遮罩与运镜测量](code-masks-and-camera.md) 的跨帧对应点流程，记录矩阵方向、置信证据与异常帧，不把拟合噪声直接写入运动轨道。
