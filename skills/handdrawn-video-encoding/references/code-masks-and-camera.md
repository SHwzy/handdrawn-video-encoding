# 代码遮罩与运镜测量

用于多种画面状态交替、人物描边、纯色人物与背景联动的镜头。以下是通过审看的制作经验，不代表恢复了原作者的工程或精确遮罩。

## 先确定图层，而不是先画遮罩

逐帧记录正常画面、纹理背景、描边人物、纯色人物、错色色块的出现与消失。把问题拆成：哪些状态在混合，边界怎样移动，人物与背景是否同时切换。遮罩本身只控制显隐，不能补救缺少的角色、背景、姿态或错误的前后关系。

同一人物的正常、描边、纯色/纹理版本共享轮廓、锚点与运动。背景另建现实、纹理、浅色等状态。角色自带 alpha 用于正常叠放；场景显隐遮罩控制状态切换；绿幕抠像和局部动画融合各有不同用途，记录时不要混为一谈。场景显隐用代码，不用 H3 生成。

## 从简单场到多层显隐

1. 在屏幕坐标中建立方向场，例如横向、反向横向或纵向坐标。加入长短两种波纹，以及固定随机种子的低分辨率噪声场，经平滑放大后形成不规则边界。
2. 用进度驱动阈值：`M = smoothstep((threshold(t) - field(x,y)) / edge_width)`，限制在 0–1。起点显式为 0、终点显式为 1；阈值必须覆盖场的完整范围，避免结尾残留。
3. 单条波浪边界仍然简陋时，依据原片加入弯曲主带、延迟出现的支带、独立窗口或岛状开口。通过合并/相减形成实际观察到的拓扑，而不是不断增加随机噪声。
4. 背景与人物使用独立时间包络，允许有证据支持的短暂错位：背景先变、人物描边随后显露，再切纯色，最后恢复正常画面。不要用全画面一次交叉淡化替代这些状态。
5. 错色色块作为独立底层，在随后显露的图层之下迅速被盖住。按原片采样紫、红、亮绿、蓝等颜色与块状结构，不能用水墨背景代替错误感。去色、闪光、模糊也各自使用强度包络。

图像状态混合可用 `C = A*(1-M) + B*M`。人物合成先预乘 alpha，再滤波/变换；避免重复乘 alpha 导致边缘发黑、变淡。外描边可由 `dilate(alpha)-alpha` 得到，但人物内部线条改色、纯色剪影和外描边是三种不同效果，不能互相替代。

人物内的印花在人物局部坐标生成，随人物运动；屏幕擦除边界通常在屏幕坐标计算。只有原片证据表明遮罩绑定角色时，才随角色变换。先检查灰度遮罩的起、中、末帧，再检查完整合成；切点前后逐帧核对遗漏的小岛、层间错位、边缘和色块盖过的时机。用户已认可遮罩、仅要求补运镜时，保留其形状与时序。

内部描线人物与全身纹样剪影可能在同一短镜头内先后出现，须逐状态核对。描线状态可保留发丝、袖缝等内部线；全身纹样剪影只使用人物 alpha 统一填色与铺纹样，不保留原 RGB、五官或服装分区，纹样可连续穿过头、身体和脚。不能把这种效果生成为另一套印花服装，也不能只去掉五官就认为完成了剪影。人物先变暗、背景稍后出现纹样时，分别建立状态和时间包络；共享遮罩仅用于原片中确实一起变化的部分。

## 用跨帧对应点识别运镜

先划分镜头，以实际帧率建立源帧、片内时间、裁切坐标的转换。选清晰参考帧，在相对刚性的脸部、服装或环境上选 ROI；避开摆动的发梢、手指、泪水、字幕、遮罩边界、重复纹理和强模糊。单帧头部倾斜不能证明镜头旋转。

本案例采用 SIFT 特征、近邻距离比筛选与 RANSAC 的 `estimateAffinePartial2D`，先估计平移、等比缩放与旋转，不直接上高自由度形变。明确矩阵是参考帧到目标帧，还是反向配准；两者不能直接互换。若约定矩阵为 `[[a,b,tx],[-b,a,ty]]`，则尺度为 `sqrt(a*a+b*b)`，角度按该约定用 `atan2(b,a)`，参考中心乘矩阵得到目标中心。记录库的角度单位和屏幕轴方向，用一个可见锚点核实正负号，避免旋转方向反了。

保存参考帧、ROI、匹配数、内点数、矩阵、尺度、角度、中心及残差。检查低内点、接近零尺度、突然翻转、异常中心和跨切点混入；阈值按镜头制定，不照抄案例数值。可疑帧回到原图复核，必要时在同镜头可靠关键帧之间插值，并标明估计区间。测量精度受画质与形变限制，不称为逐像素精确还原。

把整体推进/缓动与短时抖动残差分开。先用多个稳定部位验证共同运动，再决定保留哪些残差；不能把匹配噪声变成抖动，也不能把原有细微震动全部平滑掉。即使特写姿态不变，画面也可能持续平移、旋转、缩放。

## 把测量转成合成关系

- 纯镜头运动下，人物与现实/纹理背景共享旋转轨道；缩放和位移可依据深度关系不同。不能只转人物、让背景静止，也不能无证据强加视差。
- 快速向左切镜要让上一镜实际向左退出，下一镜按空间关系进入；逐帧检查切换起点、交接和结束，不能用硬切或从中途进度开始冒充旋转感。
- 先变换完整素材，再裁视窗。检查全程覆盖，缺口通过独立素材扩绘解决，不复制边缘或偷取原片补洞。
- 生成动画可能遗漏原片运镜。分别测量生成片和原片，判断已包含哪些运动，再补差异，避免二次叠加。同一案例中流泪动画采用稳定后的局部表演叠在新绘素材上，再统一施加运镜；这只适用于配准可靠且局部融合边界成立的镜头，不是所有动画的默认步骤。

最终按正常速度对照，并加密检查极值、切点和短暂特效。分别记录观察、拟合、手工修正与未确定项。代码可重放、帧数正确不等于运镜和视觉已被认可。
